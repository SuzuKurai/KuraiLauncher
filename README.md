# 🦇 Kurai Launcher
¡Bienvenido a **Kurai Launcher**! Un lanzador de aplicaciones de código abierto diseñado para ser ultra-rápido, altamente personalizable y con una estética minimalista y elegante. Optimiza tu flujo de trabajo y transforma la forma en que interactúas con tu escritorio.

## 💎 Características principales
*   **Rendimiento Ligero:** Diseñado desde cero para consumir el mínimo de recursos del sistema.
*   **Jugabilidad no premium:** Podrás jugar en No Premium, con futuro soporte para Minecraft Premium.
*   **Privacidad por Defecto:** No recopilamos tus datos de uso. Todo se procesa de manera local.
*   **Código abierto:** Revisa en cualquier momento el código que estás ejecutando entrando en este repositorio.

## 🛠️ Cómo compilar tu propia Build

Si quieres clonar el repositorio y generar el ejecutable de tu propio launcher en tu ordenador, sigue estos pasos:

### Prerrequisitos
Asegúrate de tener instalado en tu sistema:
- **Node.js** (versión LTS recomendada, incluye npm).
- **Git**.

### 1. Clonar el repositorio
Abre tu terminal y clona el proyecto:
```bash
git clone https://github.com/SuzuKurai/KuraiLauncher.git
cd tu-repositorio
```
